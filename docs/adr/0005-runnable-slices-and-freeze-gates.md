# 以可运行切片驱动接口冻结

> 2026-09-28：交付版本与阶段排期由 [ADR-0043](0043-versioned-delivery-and-gates.md) 替代。以下保留历史决策；基线、技术语义与验证原则继续有效。

M0 只冻结模块边界、依赖方向和完整目标清单；每个子系统必须在首个端到端可运行切片通过后才冻结相关接口。Chat Completions 在 M0 声明完整能力矩阵，M1 实现并冻结 DeepSeek/default-compatible 核心，M2/M10/M12 按已登记依赖关闭其余 Stub 而不重定义 M1 契约。这样能尽早交付持续可运行的 Pig，又不会凭静态空接口过早固化错误设计。
