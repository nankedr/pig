# 明确项目信任与宿主执行边界

Project Trust 是项目设置、资源、包和扩展的执行门，不是逐 Tool 审批、路径边界或 sandbox；受信内容和内建 Tool 继承宿主用户权限。Context File 即使未信任也会进入模型上下文，但 Pig 在信任结论前不读取任何 trust-sensitive 项目设置，以修复固定 Pi 快照的启动缺口。明确这些边界是为了保留 Pi 能力，同时不向用户承诺不存在的安全隔离。

本地 system prompt 输入只读取普通文件；对目录、FIFO 和设备返回可观察 warning 并保留输入值，不打开特殊文件。固定 Pi 的目录读取失败也采用保留输入值的回退；Pig 将该规则扩展至特殊文件以避免启动阻塞。显式文本/文件资源独立于项目信任，自动发现项目资源仍在信任结论前禁止读取。

本地资源加载器使用调用者已准备的 SettingsManager 信任结论，不隐式刷新注入实例或清除其临时 ApplyOverrides。未注入 settings 时，加载器自行加载全局设置并确定信任；这也避免会话切换在资源装配期间丢失调用者配置。
