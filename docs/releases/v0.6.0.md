# Pig v0.6.0

本版本集成 M6 已交付的文本交互：编辑/粘贴与按键、渲染/滚动、对话框与选择器、队列、主题/设置、Bash、外部编辑器和维护命令。CLI 与公开 Go SDK 复用 legacy AgentSession、v3 Session 和本地资源；保留 M1–M5、Headless text/json 与 Coding Agent JSONL RPC 回归。

用户于 2026-09-24 明确要求跳过本轮 [darwin/arm64 人工终端验收](../learning/m6-manual-acceptance.md)，继续发布并关闭 #125 和 #8。**人工验收未执行，不宣称真实终端或物理按键验收通过。** 冻结接受绑定确切 commit 的显式豁免记录，其余自动检查、受保护 live smoke、独立安装和公开版本安装保持必需。发布结果以 [v0.6.0 Release](https://github.com/nankedr/pig/releases/tag/v0.6.0) 附件中的日志及 verification.json 为准。

发布目标为原生 Go、CGO_ENABLED=0 的 darwin/arm64。制品包括源码归档、pig/pig-ai CLI、许可证、校验和、冻结日志、自动终端输出与 Session/HTML 副作用、人工记录或显式豁免及绑定确切 commit 的 verification.json。安装命令为：

```sh
go install github.com/nankedr/pig/cmd/pig@v0.6.0
go install github.com/nankedr/pig/cmd/pig-ai@v0.6.0
go get github.com/nankedr/pig@v0.6.0
```

范围按 Catalog 的 supported 分支与证据判断；完整 TUI 公开面仍有 inventoried/scaffolded 和 partial 条目，不宣称全部 Pi 文本组件已行为对等。复杂布局/Markdown、系统剪贴板、宿主分享、JSONL 导出、罕见协议/终端故障等缺口保持可见。包生态 #99 未排期；扩展 M7、完整认证 M11、图片 M12、六平台 M13 未完成。按用户授权，发布和公开安装验证完成后关闭 #125 与父 #8。

复现和源码导航见 [M6 冻结](../learning/m6-freeze.md)及 [TypeScript → Go](../mappings/typescript-to-go/m6-freeze.md)。
