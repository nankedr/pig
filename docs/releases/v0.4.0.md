# Pig v0.4.0

M4 交付 Headless 编排与 Coding Agent JSONL RPC：显式 grep/find/ls 与默认 read/bash/edit/write 七工具，steering/follow-up 投递、整轮 retry、动态模型/thinking/Tool、stats、手动/自动压缩、公开 SDK 树导航与分支摘要、RPC 会话控制/替换和安全 HTML export。CLI 与 SDK 版本统一为 `0.4.0`。

- 真实 CLI 测试覆盖 text/json 七工具调用、失败结果、进程退出后的恢复及 fork 隔离；SDK 组合示例验证投递、重试、配置、分支摘要、压缩与重开。
- JSONL RPC 支持并发 ID、异步事件、取消、Bash、模型/thinking、队列、stats、持久化生命周期与压缩；实际子进程验收迟到事件隔离和失败替换保留旧会话。
- HTML 导出内含离线资产，支持 Markdown、高亮、树导航与摘要；真实 Chromium 门禁覆盖渲染、XSS 和零自动 HTTP 请求。
- `make m4-gate` 集成 M1–M4 离线回归、race、取消/回收重复检查、vet、无 CGO 本机构建和示例；`make m4-freeze` 增加干净 checkout、固定 Pi Oracle/source drift、v3 双向互操作、Catalog/API 范围检查、浏览器和受保护 DeepSeek 冒烟。

默认四工具保持不变，find/grep 需要预装 fd/rg。RPC 扩展 command context 的分支摘要导航归 M7/#9，完整 Extension Surface 尚未实现；固定 Pi 没有 navigate_tree wire 命令。资源/包与主题 M5、TUI M6、扩展 M7、Harness M8、CBOR 远程协议 M9、其余 Provider/模型管理 M10/M11、图片 M12 和六平台行为 M13 继续保留明确边界。自定义 HTML renderer、消息图片和 SDK ExportToJSONL 尚未交付。本发布不宣称全量 Pi 对等。

```sh
go install github.com/nankedr/pig/cmd/pig@v0.4.0
go install github.com/nankedr/pig/cmd/pig-ai@v0.4.0
go get github.com/nankedr/pig@v0.4.0
```

发布平台为 darwin/arm64；Project Trust 不提供工具审批或 Sandbox。tag `v0.4.0` 标识经过验证的源码 commit。Release 附件包括 freeze 日志、安装二进制的浏览器验证日志、`verification.json`、无 CGO CLI tar.gz 与 SHA-256 清单。复现发布制品：`python3 scripts/m4-release.py /tmp/pig-v0.4.0-release`。详细前置条件、逐项能力证据和范围见 [M4 集成与冻结](../learning/m4-freeze.md)及 [TypeScript → Go 导航](../mappings/typescript-to-go/m4-freeze.md)。
