# Pig v0.2.0

M2 集成 Legacy AI、Agent 与 Telemetry 的高级语义：thinking/signature、usage/cost/cache、deferred response/tools、跨 Provider handoff、context overflow、steering/follow-up、proxy，以及 compat/deprecated 和 Session Resource cleanup。

- CLI `pig --version` 与 Go SDK `codingagent.Version` 均为 `0.2.0`。
- 保留 M1 的 AI Stream、Provider、Chat Completions 核心、Tool continuation 和 text/json Headless 契约。
- `make m2-gate` 提供离线集成、race、重复顺序、取消和生命周期检查；`make m2-freeze` 追加干净 checkout、固定 Pi Oracle/source drift 与真实 DeepSeek 冒烟。
- 补齐 usage/cache 和 proxy 的门禁入口，新增离线 proxy SDK 示例，固定 M2 Catalog ID 与版本检查。

这不是 Pi 全量功能发布。其他真实 Provider 协议/认证与图片能力继续按 M10/M11/M12 保持明确 Stub；Catalog 的 `partial` 和批准偏离保持可见，不宣称全部字段已通过固定 Pi 差分。M2 之后的里程碑前沿为 M3：本地持久化 Coding Agent。

发布对应的不可变源码由 Git tag `v0.2.0` 标识。完整复现方式、证据范围与剩余边界见 [M2 集成与冻结](../learning/m2-freeze.md) 和 [TypeScript 到 Go 导航](../mappings/typescript-to-go/m2-freeze.md)。
