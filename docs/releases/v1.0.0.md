# Pig v1.0.0

V1 发布 ADR-0043 批准的完整语义子集：保留 M0–M6 已交付能力，新增 DeepSeek Responses 和 production v3 图片闭环。完整固定 Pi 基线对等继续由 [#127](https://github.com/nankedr/pig/issues/127) 跟踪。

| 范围 | 本版本支持 |
| --- | --- |
| Provider | DeepSeek；目录列出的其他厂商不构成运行支持承诺 |
| API | OpenAI Chat Completions、OpenAI Responses 线协议；支持该协议不代表支持 OpenAI 官方 Provider |
| 文本配置 | Responses `deepseek-v4-pro`；既有 Chat Completions 文本模型及已交付工具链保留 |
| 图片配置 | `deepseek-flash`，双 API 用户图片和 read/ToolResult 图片、工具 continuation |
| 格式与处理 | PNG、JPEG、GIF、静态 WebP；格式校验、EXIF 方向、缩放，按矩阵登记 |
| 入口与恢复 | 公开 Go SDK、headless text/json、Interactive 附件/剪贴板、Coding Agent JSONL RPC；v3 内联保存、恢复/fork/树导航、first-kept 压缩语义 |
| 展示 | Kitty/Ghostty 有界预览及文本降级；独立、安全、离线 HTML 导出 |
| 平台 | 原生 darwin-arm64；无 CGO CLI 和公开 SDK。其他目标能编译不等于获得发布支持 |

服务支持/忽略/不支持行为见 [Responses 矩阵](../specs/responses.md)、[用户图片](../../parity/user-images-matrix.json)、[工具图片](../../parity/tool-images-matrix.json)与[图片工作流](../../parity/image-workflow-matrix.json)。模型/endpoint 记录来自当前服务来源，固定 Code/Catalog Baseline 不变。非视觉模型拒绝图片，不静默丢弃。

安装 CLI 与 SDK：

```sh
go install github.com/nankedr/pig/cmd/pig@v1.0.0
go install github.com/nankedr/pig/cmd/pig-ai@v1.0.0
go get github.com/nankedr/pig@v1.0.0
```

也可下载 `pig-v1.0.0-darwin-arm64.tar.gz`，核对 `SHA256SUMS` 后解压，将其中 `pig`、`pig-ai` 加入 PATH。`pig --version` 与 `codingagent.Version` 均为 `1.0.0`。

`go run ./examples/v1-workflow` 使用合成图片和本地 HTTP/SSE，验证工具 continuation、删除图片原文件后的 v3 恢复、独立 HTML 和压缩后续接，无需真实凭证。真实服务示例见 [冻结与安装](../learning/v1-freeze.md)。

发布必须完成 `make v1-freeze` 和安装验证。Release 附件 `verification.json` 绑定确切 commit/tag、平台、基线和日志哈希；`live-evidence/live.json` 记录强制开关、endpoint、明确模型、文档来源日期与文本/工具/视觉/原生剪贴板各项结果；`published-install.json` 记录全新 module cache、无 replace 的公开 CLI/SDK 安装及 Origin commit。通过结论以附件为准，缺凭证、服务失败或 skip 均阻断。本次使用新的自动原生 PTY、实际 NSPasteboard 与浏览器验证，不沿用 v0.6.0 人工豁免，也不宣称执行了人工物理按键验收。
