# Pig v0.3.0

M3 交付可恢复的本地 Coding Agent：v3 Session 持久化、历史恢复与 Pi/Pig 双向互操作、继续/fork、全局和可信项目 settings、canonical 文件凭证、基础 ModelRuntime，以及默认 read/bash/edit/write 的完整编码任务。

- CLI `pig --version` 与 Go SDK `codingagent.Version` 均为 `0.3.0`。
- 真实子进程覆盖四工具调用、失败结果、退出后恢复、fork 隔离和信号取消后重开。
- Project Trust 在读取项目 settings 前判定；Context File 仍可进入未信任项目的提示词。Pig 状态与 Pi 隔离，凭证写入受文件权限和锁保护，Provider 错误脱敏。
- `make m3-gate` 集成 M1/M2/M3 离线测试、race、并发/取消重复回归、vet、无 CGO 本机构建及 Go 示例。`make m3-freeze` 追加干净 checkout、固定 Pi Oracle/source drift、v3 双向互操作和受保护 DeepSeek 发布冒烟。
- M3 Catalog 快照分别保留行为证据与静态映射状态；未实现的 models.json、资源/包管理、TUI、其他 Provider、OAuth/ambient auth 和图片能力继续按 M4/M5/M10/M11/M12 的精确边界推进。

Project Trust 不是 Tool 审批或 Sandbox；工具使用宿主权限，Bash 可执行宿主命令。当前发布硬门为 darwin/arm64，六平台行为仍待 M13。`pig-ai` 与 SDK 同 module 安装，尚未交付命令继续明确失败。本发布不宣称全量 Pi 对等。

```sh
go install github.com/nankedr/pig/cmd/pig@v0.3.0
go install github.com/nankedr/pig/cmd/pig-ai@v0.3.0
go get github.com/nankedr/pig@v0.3.0
```

已验证的不可变源码由 tag `v0.3.0` 标识。发布附件提供门禁日志、绑定源码与双来源基线的 `verification.json`、无 CGO darwin/arm64 CLI 包与 SHA-256 清单。复现流程及剩余边界见 [M3 集成与冻结](../learning/m3-freeze.md)，各切片入口见 [TypeScript → Go 导航](../mappings/typescript-to-go/m3-freeze.md)。
