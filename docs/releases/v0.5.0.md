# Pig v0.5.0

v0.5.0 完成调整后的 M5 本地资源交付：CLI 和公开 Go SDK 加载 Context File、system prompt、Prompt Template、Skill 和 Theme，提供来源、优先级、冲突诊断及项目信任控制。SDK 可修改并重载资源后继续同一 Session，保留历史、持久化、分支、模型和 Tool；CLI 重开恢复时加载新资源，HTML export 使用新主题。

- 普通本地资源流程无需 Node/npm，不隐式安装依赖。拒绝项目信任时 Context File 仍加载，显式路径与禁用选项遵循各资源契约。
- 本地扩展入口只发现和诊断，执行返回明确未实现，不冻结扩展 ABI。
- [ADR-0034](../adr/0034-defer-package-ecosystem.md) 的包 manifest/登记、npm/git 管理、依赖和 lifecycle 由 [#99](https://github.com/nankedr/pig/issues/99) 保留为 V1 未完成范围，未排期且不自动移入 M7/M14。本版本不宣称完整 Pi 包对等。
- 保留 M1–M4 回归与冻结要求，新增真实 CLI/公开 SDK 组合、空 PATH、重载取消/并发、主题及浏览器验证。资源 API 沿用现有 snapshot，无新增 RPC reload 命令。

```sh
go install github.com/nankedr/pig/cmd/pig@v0.5.0
go install github.com/nankedr/pig/cmd/pig-ai@v0.5.0
go get github.com/nankedr/pig@v0.5.0
go run ./examples/m5-workflow
```

发布硬平台为 darwin/arm64、CGO_ENABLED=0。Release 附件包含 CLI 归档、许可证、freeze 和安装日志、`verification.json`、公开版本安装证据和 `SHA256SUMS`；公开安装采用新 module cache 且无 replace，核对源码 commit。复现：`python3 scripts/m5-release.py /tmp/pig-v0.5.0-release`，tag 后运行同一脚本的 `--verify-published` 模式。完整范围、前置条件和证据见 [M5 冻结](../learning/m5-freeze.md)及 [TypeScript → Go 导航](../mappings/typescript-to-go/m5-freeze.md)。父 #7 是否关闭另由维护者决定。
