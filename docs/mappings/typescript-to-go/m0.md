# M0 TypeScript 到 Go 导航

本页帮助阅读源码，不记录完成度。范围、目标阶段与 Capability Status 的唯一权威是 `parity/catalog.jsonl`；固定公开表面来自 `parity/surface/symbols.jsonl`。

| Pi 模块 | Pig 边界 | M0 API 证据 | 主要后续阶段 |
| --- | --- | --- | --- |
| `packages/ai` | `ai` | `ai/*_test.go` 与 Chat Completions matrix | M1、M2、M10–M12 |
| `packages/agent` | `agent` | `agent/issue29_surface_test.go`、`agent/issue30_surface_test.go` | M1、M2、M8 |
| `packages/coding-agent` | `codingagent` | `codingagent/issue32_surface_test.go` 与 CLI golden | M3–M8 |
| `packages/telemetry` | `telemetry`、`telemetry/testing` | `telemetry/telemetry_test.go`、`telemetry/testing/conformance_test.go` | M2、M13 |
| `packages/tui` | `tui` | `tui/issue31_surface_test.go` | M6 |
| `packages/protocol` | `protocol` | `protocol/protocol_test.go` | M9 |
| `packages/client` | `client`、`client/unix` | `client/client_test.go`、`client/static_surface_test.go` | M9 |

`parity/inventory/files.jsonl` 记录每个源码、测试、fixture、示例、文档和资产的 owning Catalog ID。`parity/catalog.manifest.json` 同时链接 Inventory 与 Surface manifest；冻结门禁要求每个 symbol、公开 member、static member 和 constructor 都存在精确 Catalog ID。

M0 的逐项补全行使用 `mapping.kind: package`、`inventoried` 与 M14 收口阶段：它只锁定精确公开 identity 和目标 Go package，不重复猜测跨阶段成员的行为进度。后续经审阅的 contract/matrix 行会接管实际 Milestone、状态和证据，符合 ADR-0005。
